# 运行说明

## 一、怎么打开

1. 解压收到的压缩包。
2. **双击 `录像标记工具.html`**（推荐 Chrome 或 Edge 浏览器，Win10/11 自带的 Edge 即可）。
   浏览器地址栏会显示 `file:///.../录像标记工具.html`，说明是本地打开，正常。
3. 不需要安装任何东西：没有 npm、没有 pip、没有服务器、不用联网。整个工具就是这一个 HTML 文件，CSS 和 JS 全部写在里面。

> 如果双击后被别的程序（记事本、编辑器）抢走打开：右键文件 → 打开方式 → 选择 Microsoft Edge 或 Google Chrome。
> 也可以在 Edge 里按 `Ctrl+O` 选这个文件。

## 二、怎么载入录像

1. 点左下角蓝色的 **「选择录像文件」** 按钮。
2. 在弹出的文件框里选中群里的 **`京津道路车流.mp4`**，点"打开"。
3. 稍等一下，播放区出现第一帧画面，按钮左边的文件条变成绿色小圆点并显示文件名，就说明载入成功。

> 录像不会被上传：浏览器只是把本地文件读进内存播放，整个过程不联网。

## 三、怎么用（三步）

| 想做的事 | 操作 |
| --- | --- |
| 播放 / 暂停 | 用视频下方自带的控制条；或点右侧「播放 / 暂停」按钮；或直接按 **空格键** |
| 给当前画面加备注 | 暂停在想记录的那一帧 → 在输入框写一句话（比如"留意右侧车道那辆白车"）→ 点 **「保存备注」** 或按 **回车**。工具自动记录当前时间，列表里立刻出现「时间 + 备注」 |
| 回看某条备注 | **点列表里的任意一条**，视频直接跳回那一刻的画面（本来暂停就还是暂停，本来在播就继续播） |

- 列表**按时间自动排序**，连续加多条不会覆盖，前面的记录都在。
- 右上角的「当前 00:08.0」和保存按钮上的时间是实时变化的，精确到 0.1 秒。
- 鼠标移到某条备注上，右侧出现 `×`，点它可以删掉这一条（加分项）。
- 点面板底部的「导出备注」，会下载一个 txt，里面是所有时间点和备注（加分项）。
- 备注**自动保存在本机浏览器里**（localStorage），刷新页面、关掉浏览器再打开都还在；不同录像按**文件名**分开存，互不干扰。
- 刷新后如果还没重新选文件，备注面板会提示「本机已存着这些录像的备注：xxx.mp4（3 条）」，选回同一个文件备注就全回来了。

## 四、常见问题

**1. 选了视频但画面一片黑 / 提示无法播放？**
浏览器不支持这个视频的编码。本工具支持 H.264 编码的 MP4（群里提供的录像就是），换成 Chrome/Edge 的最新版基本都能播。

**2. 刷新页面后，列表里没有之前的备注？**
备注按"文件名"存在浏览器里，下面几种情况会读不到：
- 换了另一个浏览器（Edge 存的，Chrome 里看不到）；
- 用了无痕 / InPrivate 窗口（关掉就清空）；
- 浏览器设置里开了"关闭时清除浏览数据"；
- 视频被改了文件名再载入。

**3. 双击没反应 / 页面空白？**
确认文件完整（HTML 是单文件，不要只拷贝一部分），并换 Edge 再试。

## 五、环境要求

- Windows 10 / 11、macOS 或 Linux 均可；
- 浏览器：Microsoft Edge 或 Google Chrome（90 版本以上即可）；
- 不需要安装依赖，不需要联网，不需要后端。
