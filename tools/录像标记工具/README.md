一、这是什么
一个纯网页小工具：回放交通录像，在想留意的画面暂停、写一句备注，必要时用绿色或红色虚线框圈出目标车辆 / 行人；保存后备注连同时间和框一起留在右侧列表，以后点任意一条，视频就跳回那一刻并重新显示框选。
二、运行环境
浏览器：Chrome、Edge 等现代浏览器均可
三、怎样打开工具
1. 打开本目录下的 “录像标记工具.html”（双击即可在默认浏览器中打开；如浏览器不合适，右键 →「打开方式」选择 Chrome/Edge）。
2. 点击页面左上角「选择录像」，载入交通录像 MP4（可一次选择多个视频）。
3. 即可开始标记与回看。
四、怎样载入录像
1. 点击页面左上角的「选择录像」按钮。
2. 在弹出的文件选择框中，选中本文件夹里的「京津道路车流.mp4」（也可以一次选中多个视频），点击打开。
3. 载入后，视频显示在左侧画面区；顶部下拉框可在已添加的多个视频之间切换。
五、标记一条画面
1. 点击「播放 / 暂停」，或直接用视频自带控制条，把画面停在想记录的时刻。
2. （可选）先在「绿色框 / 红色框」中选一种标记颜色：
3. 在画面上按住鼠标左键拖拽，拉出一个虚线圆角框，把目标圈在框内。拖错了可点「清除当前框」，只取消这个还没保存的草稿框，不影响已保存的备注。
4. 在下方输入框写一句备注（例如：留意右侧车道的白车），按回车或点「保存标记」。
5. 保存后，右侧列表会出现这条记录：显示时间、颜色圆点和备注文字。
6. 继续播放，到其他时刻可按同样方式添加更多备注；前面的记录都会保留。
六、怎样回看某条备注
在右侧列表点击任意一条备注：视频会跳回该备注对应的时刻并暂停，若当时画了框，对应的绿 / 红虚线框会重新显示在目标上。
六、已知限制
1.视频以浏览器本地临时地址载入：刷新页面后需要重新选择载入视频；备注记录仍保留在本地存储中，载入对应视频后可正常回看。
2.本地备注只保存在当前浏览器，更换电脑或浏览器后不会跟随，需重新标记。
3.工具只在本机浏览器运行，不会把录像或备注上传到任何服务器。
