# 录像标记工具

给交通监控录像做"时间点备注"的单文件网页工具：播放/暂停录像，把画面停在想记录的那一刻，写一句话，工具自动记下当前时间；之后点列表里的任意一条，视频立刻跳回那一刻。

## 用途

看长录像做人工标注/取证时，靠记时间码来回拖进度条非常费劲。这个工具把"第几秒 + 一句话"直接存成列表，点一下就回到现场，笔记还能导出成 txt 交给别人。

## 运行方法

**不需要安装任何东西**，没有 npm / pip / 后端 / 联网。

1. 双击 `录像标记工具.html`，用 Microsoft Edge 或 Google Chrome 打开（Win10/11 自带 Edge 即可）。
2. 地址栏是 `file:///...`，说明是本地打开，正常。
3. 点左下角「选择录像文件」，选中一份 H.264 编码的 `.mp4`。
4. 播放/暂停（空格键也行）→ 停在目标画面 → 输入备注 → 「保存备注」（或回车）。
5. 点列表里任意一条 → 跳回对应画面。

详细步骤见 [运行说明.md](运行说明.md)；开发/验证过程见 [AI使用文档.md](AI使用文档.md)。

## 输入输出

| | 内容 |
| --- | --- |
| 输入 | 本地 `.mp4` 录像（H.264）。通过文件选择框读入内存播放，**不上传、不联网** |
| 输出 | ① 界面里的备注列表（时间 + 文字，按时间排序）<br>② 持久化：浏览器 `localStorage`，键为 `traffic-video-markers::v1::<视频文件名>`，不同录像按文件名隔离<br>③ 点「导出备注」下载 txt，格式见 [示例导出-视频-备注.txt](示例导出-视频-备注.txt) |

导出示例：

```
录像：视频.mp4
导出时间：2026/11/20 00:17:12
共 3 条备注
----------------------------------------
00:01.4    最下方有身穿黄色衣服骑手驶离
00:03.3    左下方有白色面包车驶入
00:06.2    有黄灰色大巴驶入
```

## 已知限制

- 只支持浏览器能解码的格式（H.264 MP4 最稳）。HEVC/H.265 的录像在部分浏览器里放不出来。
- 备注存在**当前浏览器**里：换浏览器、开无痕窗口、或浏览器设置成"关闭时清数据"，都会读不到旧备注。
- 备注按**文件名**关联录像。刷新页面后浏览器出于安全限制不会自动读回本地文件，需要重新选一次同名文件，备注会立刻恢复（面板上有提示）。
- 刷新后若尚未重新选文件，列表显示的是占位提示，不是备注丢失。
- 单文件、无后端，因此没有多人协作和云端同步。
