在进行操作前需要确定电脑是否安装opencv-python（视频处理库）
关于操作标记车流步骤：
1、首先点开文件所在目录，双击打开run.py文件或者在上方输入框输入cmd，输入”python run.py”；
2、进入工具后点击播放键，开始播放，在需要标记的地方输入需要标记的内容，点击确定备注即可，可重复标记视频其他地方；
3、点击备注可回到标记画面
