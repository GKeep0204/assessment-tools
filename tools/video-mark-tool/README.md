# 交通录像标记工具（video-mark-tool）

用于在观看交通车流录像时，在关键画面上暂停并留下文字备注，形成"时间点 + 观察要点"的清单，便于队友按时间点回看同一段画面。

- 负责人：曹一彤（cyt）
- 演示视频：见下方「演示视频获取方式」

## 用途

看录像时发现可疑车辆、变道、违停等需要重点观察的画面，随手记一条备注并自动记下当时的时间点；之后点一下清单里的任意一条，视频就跳回那个画面，无需手动拖动进度条估算位置。

## 运行环境

- 系统：Windows / macOS 均可
- 软件：任意主流浏览器（推荐 Edge、Chrome）
- 依赖：无。不需要安装任何软件、不需要 Node.js / Python、不需要本地服务器、不需要联网

## 启动步骤

1. 下载本目录下的 `index.html`（或直接克隆仓库后进入 `tools/video-mark-tool/`）。
2. 双击 `index.html`，浏览器会自动打开工具页面。
3. 点击页面上的【加载录像】，选择本地的 mp4 视频；也可以直接把视频文件拖拽到播放区域。
4. 页面加载完成即可使用全部功能。

## 使用说明

1. **加载视频**：点【加载录像】选择本地 mp4，或拖拽视频到播放区域。
2. **播放 / 暂停**：点【播放】【暂停】按钮；焦点不在输入框时，按键盘空格键也可播放 / 暂停。
3. **添加标记**：把视频停在需要观察的画面上，在输入框写下备注，点【保存当前画面标记】。工具会自动记录当前时间点并暂停视频。快捷键 `Ctrl + Enter` 可快速保存。
4. **跳转回看**：点击右侧清单中任意一条，视频自动跳到对应时间点的画面。
5. **管理标记**：单条可删除，也可一键清空全部；点【导出备注】可把全部时间点和备注导出为 txt。
6. **自动保留**：备注保存在浏览器本地，关闭页面再打开同一个视频，标记会自动恢复。

## 输入输出

- 输入：本地视频文件（mp4），以及人工填写的文字备注
- 输出：
  - 页面内的标记清单（时间点 + 备注，按时间可跳转）
  - 可导出 `视频名-标记备注.txt`，格式为 `序号. [分:秒.十分秒] 备注内容`
  - 浏览器本地缓存中的标记数据

## 已知限制

- 只支持浏览器能解码的视频格式，推荐使用 mp4（H.264）；部分 avi / mkv 可能无法播放。
- 标记保存在当前浏览器的 localStorage 中，清理浏览器缓存或换浏览器会看不到原来的标记。
- 标记以「视频文件名 + 文件大小」作为识别依据，改名或换文件后不会关联到原标记。
- 导出为纯文本，不含画面截图。
