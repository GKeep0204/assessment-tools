# AI 使用文档

## 一、实际遇到的问题

本次需要开发一款「交通录像标记」网页小工具，核心要求是：

1. 能加载本地 mp4 视频并播放、暂停；
2. 暂停后能输入文字备注，并自动记录当前视频播放时间；
3. 所有备注累加显示成清单，互不覆盖；
4. 点击清单里任意一条，视频自动跳转到对应时间点的画面。

我有 HTML 基础，会写页面结构和样式，但**不清楚怎样用 JavaScript 读取视频当前的播放时间，也不清楚点击清单后怎样让视频跳转到指定时间**，这两个核心逻辑自己写不出来，因此向 AI 求助。

## 二、围绕这个问题的完整对话

**我：**

我需要做一个交通录像标记网页工具，功能要求：

1. 可以加载本地 mp4 视频播放、暂停；
2. 暂停后可以输入文字备注，自动保存当前视频时间；
3. 所有备注列表累加、不丢失；
4. 点击任意备注，视频自动跳转到对应时间点画面。

帮我写一份完整、可直接运行的网页代码。

**AI：**

下面是完整的单文件网页（HTML + CSS + JavaScript 全部放在一个 `.html` 文件里），保存后双击即可在浏览器中使用，不需要安装环境、不需要服务器：

- 视频时间读取：通过 `video.currentTime` 属性取当前播放秒数，在 `timeupdate` 事件里实时刷新显示；
- 时间跳转：把清单条目的秒数写回 `video.currentTime` 即可定位到那一帧；
- 备注保存：每条备注存成 `{id, t, text}`，`t` 是秒数，用 `localStorage` 持久化，按「文件名 + 文件大小」区分不同视频；
- 其余为界面样式、播放暂停按钮、快捷键（空格播放暂停、Ctrl+Enter 保存）、单条删除、清空、导出 txt 等。

（随后给出完整代码，即本目录下的 `index.html`）

## 三、我做的检查与实际看到的结果

我把 AI 给的代码存成 `录像标记工具.html`，在浏览器里加载了京津道路车流录像，在 02.0 秒、05.0 秒、07.5 秒三个画面各写了一条备注并保存，然后**点清单里的第 2 条**，实际看到视频**自动跳到了 05.0 秒那一帧**，三条备注也都保留在清单里没有被覆盖，三个时间点的画面与备注内容一一对应。
