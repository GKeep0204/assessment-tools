# 欧俊志-录像标记工具

## 用途

路镜是一个完全在浏览器本地运行的交通录像标记工具。使用者可以在指定画面添加带时间戳的备注，并从备注列表跳回对应画面，便于多人复核同一段交通录像。

## 运行环境

- Windows 10/11
- Microsoft Edge 最新版
- 无需安装 Python、Node.js、YOLO 或其他依赖
- 无需联网，视频不会上传

## 启动方法

1. 使用 Microsoft Edge 打开本目录中的 `index.html`。
2. 也可以右键点击 `index.html`，选择“打开方式 → Microsoft Edge”。
3. 点击页面右上角的“载入录像”，选择 `京津道路车流.mp4`。

## 使用方法

1. 播放录像到需要标记的画面后暂停。
2. 在右侧输入备注，点击“保存当前画面”；按 `Enter` 也可以保存。
3. 点击备注列表中的时间或备注文字，视频会暂停并跳回对应时刻。
4. 备注会自动保存在当前浏览器中，并按视频分别保存。

## 输入与输出

- 输入：本地 MP4、WebM 等视频文件，以及一行最多 120 个字符的画面备注。
- 输出：带有时间戳的备注列表；点击备注可直接回到对应视频画面。
- 示例标记：`00:01.12`、`00:02.79`、`00:06.34`。

## 已知限制

- 备注保存在浏览器 `localStorage` 中；换浏览器或清除站点数据后不会保留。
- 浏览器需要支持所载入视频的编码，推荐使用 H.264 编码的 MP4。
- 本工具不包含 YOLO 或其他自动识别功能。

## 文件说明

- `index.html`：工具页面入口。
- `styles.css`：工具页面样式。
- `app.js`：播放、备注、跳转和本地保存逻辑。
- `运行说明.html`：使用说明。
- `AI使用文档.html`：围绕实际问题整理的人工智能对话与验证记录。
- `AI验证截图.jpg`：点击旧备注后回到对应画面的验证截图。
- `说明文档.css`：HTML 说明文档样式。
