运行说明

完全在浏览器本地运行的交通录像标记工具。无需安装 Python、Node.js、YOLO 或其他依赖，也不需要联网。

推荐使用 Microsoft Edge 打开
打开方式：建议右键点击 index.html，选择“打开方式 → Microsoft Edge”。两份说明文档已经改成 HTML，也可以直接用 Edge 打开，不会再被 Word 打开。

使用步骤

  1. 解压整个压缩包，保持 HTML、CSS 和 JavaScript 文件在同一个文件夹内。
  2. 用 Microsoft Edge 打开 index.html。
  3. 点击页面右上角的“载入录像”，选择群里的 京津道路车流.mp4；也可以直接把视频拖进播放器区域。
  4. 播放到需要记录的画面后暂停，在右侧输入备注，点击“保存当前画面”。按 Enter 也可以保存。
  5. 后续点击备注左侧的时间或备注文字，视频会暂停并跳回对应时刻。

视频只通过浏览器的本地对象地址读取，不会上传。备注按视频自动保存在当前浏览器中；重新打开工具并载入同一段视频后，已有备注仍会显示。

演示中的 3 条标记

演示视频.mp4（百度网盘，提取码 rhzf） 在实际操作中依次添加了以下内容：

时间 备注内容
00:01.12 留意右侧白色面包车驶入路口，观察它与右侧轿车的通行顺序。
00:02.79 注意左下方黄绿色出租车即将进入路口，跟踪它的左转路径。
00:06.34 黄蓝相间公交车横穿画面，留意它遮挡右侧车道的情况。

视频末尾从较晚时刻点击第二条旧备注，画面回到黄绿色出租车驶入路口的位置，并显示“已回到 00:02.79”。

文件清单

  • index.html：工具页面。
  • styles.css：工具样式。
  • app.js：播放、标记、跳转和本地保存逻辑。
  • 运行说明.html：本说明。
  • AI使用文档.html：AI 使用记录和实际验证结果。
  • AI验证截图.jpg：点击旧备注后的验证截图。
  • 演示视频.mp4：3 条标记及点击旧标记回看的操作录像。
  • 说明文档.css：两份 HTML 说明文档的样式。

常见问题

  • 如果视频无法播放，请确认使用的是最新版 Microsoft Edge，并确认视频为 MP4（H.264）格式。
  • 如果浏览器提示不允许加载本地文件，可在解压后的文件夹中打开命令行并运行 npx serve，再用终端显示的地址访问；这是可选的本地预览方式，不是必须安装的依赖。
  • 标记保存在浏览器本地。清除浏览器站点数据后，已有标记会被删除。
