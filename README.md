# 考核小工具

本仓库用于组员提交、共享和维护考核小工具。

## 提交方式

每个工具放在 `tools/工具名称/` 目录下，并在目录中提供自己的说明文档。请优先提交源代码和必要的轻量示例数据；视频、原始采集素材和大型压缩包请通过团队约定的网盘共享，并在说明文档中写明获取方式。

建议流程：从 `main` 拉取最新代码，创建个人分支，提交工具后发起 Pull Request，由负责人检查后合并。

## 工具目录建议

```text
tools/
  示例工具名/
    README.md       # 用途、运行方法、输入输出、负责人
    ...             # 源代码与必要配置
```

## 提交要求

- 工具目录和文件名使用清楚、稳定的名称。
- README 写明运行环境、安装/启动步骤、输入输出和已知限制。
- 不提交密码、令牌、个人隐私数据或未经许可公开的素材。
- 不提交虚拟环境、缓存、构建产物或大型视频素材。
