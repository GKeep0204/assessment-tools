关于操作标记车流步骤：
1、首先点开文件所在目录，双击打开templates-index.html文件或者在上方输入框输入cmd，输入”python app.py”，复制网址http://127.0.0.1:5000/打开即可看见工具页面；
2、进入工具后点击播放键，开始播放，在需要标记的地方输入需要标记的内容，点击确定备注即可，可重复标记视频其他地方；
3、点击备注可回到标记画面。
AI使用：
1、代码由AI生成，利用AI进行一些关于代码的具体的作用学习，以及在运行工具时改进相关操作使用；
2、打开网页时出现双击打不开，咨询AI并使用终端获取网址打开进行标注；
3、运用AI修改在试用时遇到的问题，如播放视频时出现无法连续播放以及网页打开出现问题。
